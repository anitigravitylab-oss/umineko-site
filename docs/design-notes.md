# デザインノート — 2026-10-20 全面リニューアル

以前のデザインはすべて破棄し、ゼロから作り直しました。引き継いだのは次の3点だけです。

- ロゴ
- URL（`/`, `/operator/`）
- 配信設定

## コンセプト

**伝えたい気持ちが、波紋のように届く。**

- ロゴにある空・水平線・海とカモメを、そのまま最初の画面に置いています。
- 海に落ちた一滴（コーラル色の点）から、波紋が広がります。これは「声が届いていく様子」を表しています。
- 落ち着いた海の色の中に、熱い気持ちを表すコーラル色をひとつだけ使っています。

## 配色

ロゴから色を取り、アクセントを一色だけ足しました。

| 用途 | 値 |
| --- | --- |
| インク（文字・ボタン） | `#102c46`（ロゴのカモメ） |
| 空 | `#dff0f5` / `#eef7f9` |
| 海 | `#86c5d3` / `#5aa9bd` |
| 夜（「これから」の章・フッター） | `#0b1d30` |
| 気持ち（アクセント） | `#f0603d`（大きな文字・図形用）／ `#b33a22`（小さな文字用） |

コーラル色の使いどころは、「ゼロ」、章番号、進行バー、心の声の吹き出しに絞っています。小さな文字には、白地でコントラスト比4.5以上になる `--coral-ink` を使います。

## 文字

- システムフォントを使っています（Hiragino Sans / Noto Sans JP / BIZ UDPGothic など）。Webフォントは読み込まないので、表示待ちが発生しません。
- 見出しは極太にして `palt` で字詰めしています。
- 改行位置は `word-break: auto-phrase` で整えています。対応していないブラウザに備えて、要所は `.ph`（改行しない文節のまとまり）でも区切っています。

## 操作と画面の流れ

縦スクロールを基本に、各章の中でタップによって段階的に内容が出てくる作りにしています。

- **01 なぜ**：4ステップのストーリー
  1. 心の声
  2. 口に出る一言
  3. コストの差
  4. ゼロ

  進め方は「次へ」ボタン、絵のタップ、左右スワイプ、矢印キー、上部の進行バーです。
- **02 ビジョン**：原則を3枚のカードで示します。スマホでは横にスワイプして、ドットで位置を表示します。
- **03 プロダクト**：Zetterとあめ→はれをタブで切り替えます（矢印キーにも対応）。3つの特徴を選ぶと、スマホ画面の中身が切り替わります。
  - スマホ：特徴カードを横にスワイプしても画面が連動します。
  - PC：特徴を縦に並べて表示します。
- **04 これから**：AIパートナー構想を3ステップの図解で示します。「構想」と明記しています。
- **05 うみねこのこと**：つくり手の文章と、裏返して読む名前カード。
- **06 つかってみる**：サービスへのリンクを大きく置き、お問い合わせは控えめにしています。

ヘッダーには章のハイライトと、読み進めた量を示すバーがあります。スマホのメニューはネイティブの `<dialog>` で、Escapeキーで閉じられます。

## アクセシビリティと、表示が欠けたときの対応

- JavaScriptがなくても全部読めます。ステップは一覧で表示され、プロダクトは両方とも縦に並び、メールリンクも残ります。
- `prefers-reduced-motion` が有効な場合は、波紋や浮遊などの動きを止め、スクロール演出もせずに最初から表示します。
- 画面外にある装飾アニメーションは一時停止します。
- 操作できる要素はすべてネイティブの `button` / `a` です。状態は `aria-current`, `aria-pressed`, `aria-selected`, `aria-expanded` で伝え、キャプションは `aria-live` で読み上げます。
- 名前カードは、裏返していない面を `inert` にして、フォーカスが入らないようにしています。

- あめ→はれ：公式サイト am-hr.com の説明文（気持ちに合わせて表示先が切り替わる疲れないSNS、安心して弱音や日常を書ける場所）

- 利用者数、料金、AIモデル名、実績・受賞歴は載せていません。
