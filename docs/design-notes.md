# デザインノート — 2026-10-20 全面リニューアル（第3版）

## 経緯

- **第1版**：淡い水色のグラデーションに、色が多すぎました。
- **第2版**：白黒にして整えたものの、無難なテンプレートのような見た目になりました。
- **第3版**：ポートフォリオサイトの参考集（SANKOU! のポートフォリオサイト一覧）を見て、良いサイトに共通する考え方だけを取り入れて作り直しました。
  - 色は1色をはっきり決めて、面で使う。
  - 自分だけの印（シンボル）を持つ。
  - 文字を大きく、思い切って使う。

  特定のサイトのレイアウトや素材は使っていません。

## コンセプト

**「0」と、うみねこ。**

- ビジョン「コミュニケーションコストを**ゼロ**にする」の「0」を、ブランドのマークにしています。
- 細い線の大きなイタリックの「0」から、波紋のように輪が広がります。そこを、ロゴのカモメが飛び抜けていきます。
- うみねこという名前と、ビジョンを1枚の絵にまとめています。

## 配色

ブロックごとに色を切り替えて、リズムをつくっています。

| ブロック | 用途 |
| --- | --- |
| うみねこブルー `#0b2bb0` | 最初の画面、ビジョン、つかってみる、メニュー |
| 生成り `#f3f0e8` | なぜ、プロダクト、うみねこのこと、事業者情報 |
| 夜 `#0b0b0d` | これから、フッター |

- アクセント：青の上や夜の上では空色 `#9fd4ff`、生成りの上ではブルーを使います。
- 文字色は、ブロックごとの変数（`--fg` / `--fg-2` / `--fg-3`）で切り替えます。小さな補助文字も、コントラスト比4.5以上を確保しています。
- ヘッダーの色は、その下にあるブロックの色に合わせて自動で変わります。

## 文字

- **和文**：Pretendard JP（Zetterと同じ書体）。見出しは800、本文は400です。
- **数字と「0」**：Instrument Serif のイタリック。章番号（01〜06）、No.01、ステップ数に使います。
- どちらも SIL OFL 1.1 で、サイトで使う文字だけに絞って同梱しています。
  - Pretendard JP：約156KB
  - Instrument Serif：約10KB
  - 作り直すときは `tools/build_font.py` を実行してください。
- 文節の途中で改行させないために `.ph` を使っています。ただし、狭い画面で `.ph` が1行に収まらないとはみ出します。長い言葉は区切ってください。320pxでのはみ出しは、ブラウザチェックで検出されます。

## プロダクトの見せ方

- プロダクトは、番号付きの一覧（No.01 Zetter / No.02 あめ→はれ）から選びます。
- 画面イメージは、各サービスの世界観の色の上に置いています。
  - Zetter：Castのような夜空
  - あめ→はれ：空色と太陽
- 画面の中身は、実際の見た目に合わせたサンプルです。人物名・投稿・会話はすべて架空です。ログインが必要な画面（Cast の会話、あめ→はれのタイムライン）は、実物を確認できていないため、配色だけ合わせています。

## 操作

- 「なぜ」「これから」は、タップで進むステップです。
- プロダクトは、特徴を選ぶと画面が変わります。スマホでは特徴カードを横にスワイプしても連動します。
- 名前カードは、タップで裏返ります。
- スマホのメニューは全画面のブルーで表示します。
- 最初の画面のマークは、スクロールに合わせて少しだけ動きます。

`prefers-reduced-motion` が有効な場合は、これらの動きをすべて止めます。JavaScriptがなくても、全部の文章が読めます。
