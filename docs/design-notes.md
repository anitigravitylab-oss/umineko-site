# デザインノート — 2026-10-20 全面リニューアル（第2版）

「スマホで見るとダサい」というフィードバックを受けて、見た目を作り直しました。

第1版の問題は次の3つでした。

- 淡い水色のグラデーションを広い範囲に使っていた。
- 色が多すぎた（紺・水色・海色・コーラル・紫・黄色）。
- システムフォントを極太で使っていた。

第2版では、白と黒を基本にして、青を1色だけ使います。文字は Pretendard JP で組んでいます。

## コンセプト

**伝えたい気持ちが、波紋のように届く。**

- 最初の画面は文字だけで構成しています。
- 「ゼロ」の位置から、細い波紋がゆっくり広がります。
- 装飾は最小限にして、言葉そのものを主役にしています。

## 配色

| 用途 | 値 |
| --- | --- |
| 地 | `#ffffff`、面は `#f5f6f8` / `#eceef1` |
| 文字 | `#111316`、補助は `#4a5059` / `#6b727b` |
| 罫線 | `#e6e8ec` |
| アクセント | `#0a66f0`（「ゼロ」・章番号・進行バー・波紋）。白地での小さな文字にもコントラスト比4.5以上 |
| 夜（「これから」・フッター） | `#0b0d11`、アクセントは `#7cc4ff` |

影はほとんど使っていません。面の切り替えは、背景色と細い罫線で行っています。

## 文字

- **Pretendard JP**（SIL OFL 1.1）を使っています。Zetterと同じ書体なので、プロダクトとサイトの印象がそろいます。
- フォントは、サイトで使う文字だけに絞り込んで同梱しています（`public/assets/fonts/PretendardJP-subset.woff2`、約150KB、太さ可変）。
- 外部のCDNには頼りません。ライセンスは `public/assets/fonts/OFL.txt` に置いています。
- 本文の文字を変えたら、`python3 tools/build_font.py` で作り直してください。足りない文字は構造チェックで検出されます。
- 見出しは700、本文は400で組み、見出しの字間は −0.02em です。
- 見出しは文節の途中で改行されないように、`.ph` と `word-break: auto-phrase` で区切っています。

## プロダクト画面の再現

画面イメージは、公開ページで見られる実際の見た目に合わせて作りました。人物名・投稿・会話・アイコンはすべて架空のサンプルで、実際のスクリーンショットや他人の投稿、キャラクター画像は転載していません。

- **Zetter SNS**：白地に `#1c1c1e` の文字。上部に「Z」のロゴ、「おすすめ／みんな」のタブ。トピックタグは `#286aa8`、いいねは `#f91880`。下部にナビゲーション。
- **Zetter Cast**：`#050506` の黒地に青い吹き出し（`#3d8bff`）。会話画面はログインが必要で、実物を確認できていません。キャストページの配色に合わせています。
- **あめ→はれ**：地は `#ebf1f5`、ヘッダーは `#7db9de`、ボタンは `#f9d05e`、文字は `#4a4a4a`。タイムラインはログインが必要で、実物を確認できていません。「はれ／あめ」の切り替えはイメージです。

## 操作と画面の流れ

縦スクロールを基本にして、章の中ではタップで段階的に内容が出てくる作りにしています。

- **01 なぜ**：4ステップのストーリーです。進め方は、次へボタン、絵のタップ、スワイプ、矢印キー、進行バーです。
- **02 ビジョン**：原則を3つ並べています。スマホでは縦の一覧、PCでは3列です。
- **03 プロダクト**：タブで切り替えます。特徴を選ぶと、スマホ画面の中身が変わります。スマホでは特徴カードを横にスワイプしても連動します。
- **04 これから**：構想を3ステップの図解で示しています。
- **05 うみねこのこと**：つくり手の文章と、裏返して読む名前カード。
- **06 つかってみる**：サービスへの入口と、お問い合わせ。

タップの案内は、スマホでは「タップで次へ」、マウスでは「クリックで次へ」と表示します。

## アクセシビリティと、表示が欠けたときの対応

- JavaScriptがなくても全部読めます。
- `prefers-reduced-motion` が有効な場合は、動きを止めます。
- 画面外にある装飾アニメーションは一時停止します。
- 操作できる要素はネイティブの `button` / `a` です。状態は ARIA 属性で伝えています。
- 名前カードの裏返していない面は `inert` にしています。

## 内容の根拠

- ビジョン・文章：本人へのインタビュー（`docs/vision.md`）
- Zetter・あめ→はれ：各公式サイトの説明文と公開ページの見た目
- 利用者数、料金、AIモデル名、実績は載せていません。

## 確認したこと・していないこと

確認したこと：

- ローカルのChromiumで、320〜1920pxの7つの幅を表示
- 操作のテスト
- JavaScriptを切った状態の表示
- モーションを減らす設定での表示
- Webフォントの読み込み

確認していないこと：

- iPhone実機のSafari
- 本番環境での配信
- ログインが必要な実画面との突き合わせ
