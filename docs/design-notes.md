# Portfolio redesign — 2026-09-20

## リサーチ

日本のWeb制作・デザイン会社の公式サイトを確認し、情報の組み立てを参考にしました。文章、画像、コード、個別のデザインを転載・複製していません。

- ベイジ — https://baigie.me/
  事業内容、実績、進め方、会社情報、問い合わせという明確な案内。うみねこでは、サービスの説明と事業者情報を迷わず読める構成に反映。
- mount inc. — https://mount.jp/
  ポートフォリオだけでなく、考え方・アプローチ・サービス領域を分けて伝える構成。うみねこでは「プロダクト」「ビジョン」「つくるときに大切にしていること」に反映。
- SHIFTBRAIN — https://shiftbrain.com/
  プロジェクトを中心に、制作物とその背景を伝えるポートフォリオ。うみねこでは、2つのサービスの特徴が分かる大きな紹介ビジュアルに反映。

## うみねことしての方向性

- 個人事業であることを明記し、法人・大規模組織・受託実績があるようには装わない。
- 白に近い背景、ブルー、余白、日本語の大きな見出し、細い罫線。写真の寄せ集めではなく、プロダクトの仕組みとオリジナル線画を主役にする。
- 人とAIが自然に共存する日常を目指す、という本人の方針を中心にする。
- トップの `u.` はタイポグラフィによる装飾。既存ロゴPNGは維持し、favicon / Apple touch icon / OGPで引き続き使用。
- 自動再生動画、常時動く装飾、外部フォント、大きなライブラリーは追加しない。

## 内容の根拠・公開範囲

- サービスURL、連絡先、事業者情報の請求時提供文言は既存サイトから引き継いだ。
- Zetter: https://z-etter.com/ と本人の説明をもとに、SNS + Zetter Castとして紹介。うみねこが企画・開発・運営。
- あめ→はれ: https://am-hr.com/ と本人の説明をもとに、気持ちによって分けるSNSとして紹介。運営はしゃち、開発はうみねこ。
- 氏名、住所、電話番号などを記憶から新規公開していない。
- 変動する利用者数、売上、料金、AIモデル名、未確認の実績や受賞歴は記載していない。
- 画面例の人物名・投稿・会話は架空。実ユーザーの投稿やキャラクター画像は転載していない。画面は実サービスのスクリーンショットではなく、特徴を伝える説明用のHTML/CSSビジュアル。

## 実装と確認

既存の静的配信方式と `/operator/`、404を維持。依存ゼロで、JavaScriptなしでも本文とリンクを利用可能。あめ／はれの切替はネイティブbutton、状態は `aria-pressed`、サンプル内容は `aria-live`。メニューはEscapeで閉じてボタンへフォーカスを戻す。コピー失敗時はエラーを表示し、メールリンクを常に残す。`prefers-reduced-motion` に対応。

隔離された実装環境では既存PNGをダウンロードできなかったため、元のGitHubツリーにあることを確認して保持した。ローカル構造テストでは `--allow-existing-brand-assets` を使用し、この未変更PNGだけ検証対象から除外した。Chromiumの検証はページ内容をインライン化したローカルレンダリングで実施。実機iOS / Safari、本番HTTP配信、外部リンクの実際の遷移、実OSクリップボードは未検証。
